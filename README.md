# Netenum
Authors: Karim and Cavid

Netenum allows users to use some of the most popular enumeration tools in one line and get a good output of it, something like linPEAS for the enumeration stage.

```bash
git clone http://KarimAlz/netenum
cd netenum
```

Usage examples:
```bash
./main.py #prints the whole usage guide
./main.py -t 10.10.10.10 -p nmap
./main.py -t 10.10.10.10 -w nikto
```

This tool is still in active development and any tools that will be used in it will be credited. Thanks to everyone contributing both directly and indirectly
